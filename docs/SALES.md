# 售卖与价格实验

## 当前交付方式

用户在小红书或闲鱼完成平台内交易后，自动发货工具发送固定网页地址和一个独立的六位数字验证码。购买者打开网页并先输入验证码，随后可以发起双人测试；受邀者通过专属邀请链接加入，无需验证码。双方答完后自动获得完整关系报告。

每个验证码可跨设备、长期、重复用于多组双人测试。后台可以单独停用某个验证码；停用只阻止后续使用，不会删除已经生成的报告。

## 上架前必须写清楚

- 产品是娱乐与自我探索内容，不是心理或医疗诊断。
- 需要购买者和邀请的 TA 分别完成 30 道题，才能生成双人报告。
- 一份订单对应一个可重复使用的验证码。购买者先验证再发起测试，受邀者无需输入验证码，双方答完都能看完整报告。
- 展示完整报告样例，说明交付内容与解锁码的使用方式。
- 退款、有效期和售后规则以实际销售平台允许的规则为准。

## 生成解锁码

先部署数据库迁移，再在 `server` 目录执行：

```bash
npm run codes:create -- --count=20 --price=990 --variant=price_9_9 --channel=xiaohongshu
```

第二阶段切换为 19.9 元：

```bash
npm run codes:create -- --count=20 --price=1990 --variant=price_19_9 --channel=xiaohongshu
```

闲鱼渠道把 `channel` 改为 `xianyu`。生成结果也可以从管理后台导出 CSV 并导入自动发货工具。每笔订单发一个独立验证码，便于后续单独停用和查询使用次数。

## 管理后台

在服务端环境变量中配置：

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=请替换为足够长的随机密码
```

部署后访问 `/admin`。管理后台支持数据概览、代理管理、批量生成验证码、搜索、启停、导出 CSV 和系统设置。不要公开管理地址和密码。

导出的有效验证码可以导入小红书自动发货工具。自动回复文案可使用：

```text
关系引力测试网址：https://你的域名/
验证码：{{验证码}}
请复制到手机浏览器打开，验证码为 6 位数字且不能有空格，可重复使用。
如有问题请联系店铺客服。
```

小红书下单时填写的姓名和手机号属于订单收货/联系信息。手机号可由平台或自动发货工具用于订单通知、短信发码和售后联系；本项目网页不读取，也不保存姓名和手机号，只校验发放的六位验证码。

每个阶段至少记录：商品访问数、付款订单数、解锁数、退款数、客服耗时和渠道成本。用净利润比较价格，而不是只看订单量。
